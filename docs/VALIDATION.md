## 契约检查

- 13 项课件需求/补充需求分类均有 operationId 映射。
- 63 个 operationId：40 个已实现，23 个预留；预留端点返回结构化 501，不创建 job 或写文件。
- 能力信息与注册表一致：`archive` / `compression` / `encryption` 只公布实际算法，并标注 `selfImplemented`。
- 显式请求未实现的筛选、元数据、链接保真、打包/压缩/加密流水线或覆盖策略时拒绝执行，不退化成普通备份。
- OpenAPI、前端调用端、类型声明、需求表与唯一注册表保持一致。
- 持久化任务 DTO 不允许保存临时 secretRef。
